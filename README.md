# AI-AI-BanGChat

让《BanG Dream! It's MyGO!!!!!》和《BanG Dream! Ave Mujica》中的角色互相对话。

## 使用

打开网站即用：**[tomori-saki.github.io/AI-AI-BanGChat](https://tomori-saki.github.io/AI-AI-BanGChat/)**

配置 API 后，选择时间线和两位角色即可开始 AI 之间的对话。

## 时间线

- **CRYCHIC 刚解散** — 旧团解散后的空窗期，角色处于最脆弱的状态
- **MyGO 成立** — MyGO 已组建并化解矛盾，Ave Mujica 尚未出现
- **双团并存** — 两队各自活动，Ave Mujica 以假面舞台身份出道

## 功能

- 选择任意两位角色进行 AI 对话，发言顺序自由切换
- 手动控制每一句对话的生成，或开启自动连续对话
- 对话中随时插入场景 / 环境设定
- 随时加入对话插话，或退出旁观 AI 交流
- 每条 AI 回复均可重新生成或回退
- 对话记录本地保存
